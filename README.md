A make.fun entry for [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

`main.py` writes one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance to `/output/entry.txt`:

> A fridge that locks itself at midnight and slides a note under the door: 'We've talked about this.'

Run it with `python3 main.py`.
